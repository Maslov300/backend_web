## Запуск

В корне `backend_web` создайте виртуальное окружение, активируйте его, установите Flask и запустите приложение:

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install Flask
flask --app app --debug run
```

Откройте `http://127.0.0.1:5000/`.

- Лабораторная №1: `/lab1`;
- Лабораторная №2: `/lab2/`;
- Лабораторная №3: `/lab3/`.

Каталоги `venv`, `__pycache__` и локальный журнал `access.log` не должны попадать в git.

Иллюстрации галереи лабораторной №2 (20 фруктов и овощей) созданы из локального шрифта Noto Color Emoji (Google, SIL Open Font License 1.1): https://github.com/googlefonts/noto-emoji.

Настройки скрытия папок в VS Code находятся в `.vscode/settings.json`, а рекомендация расширения Jinja — в `.vscode/extensions.json`.
